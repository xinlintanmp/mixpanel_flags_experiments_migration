This tool calls the Firebase Remote Config REST API directly from your browser (read-only — nothing is written back to Firebase). Your access token is a secret — only run this tool locally / on a trusted machine, and never share the page with the token filled in.
↩ Restored your previous session from this browser — credentials, fetched flags, and selections were reloaded. Use Clear saved state to wipe them.
Firebase
Generate a token with gcloud auth print-access-token, or use a service account scoped to https://www.googleapis.com/auth/firebase.remoteconfig. Tokens expire after about an hour — if a fetch fails with 401, paste a fresh one.
Mixpanel
Authorization header preview will appear once both credential fields are filled.
Your entries and fetched data are saved in this browser's local storage so the page remembers state across reloads. This includes credentials — clear them when done on shared machines.

Import to Mixpanel
Creates one Mixpanel feature flag per selected Remote Config parameter.
⚠ Variant assignment key — Firebase Remote Config has no equivalent of a per-flag unit ID, so every flag is created with the assignment key (context field) set to distinct_id. If a parameter should be assigned on device rather than user, update the assignment key manually in the Mixpanel UI before enabling that flag. This cannot be changed once a flag is enabled.

⚠ Targeting is not migrated — Only Firebase percentage rollouts carry over. Conditions on OS, country, app version, user property, audience, installation ID or custom signals are dropped; see the report in step 3 for the exact list.
