How it works
1
Connect your provider
Enter your existing provider's API credentials. The tool fetches all flags directly from your account — nothing is stored or sent anywhere except your own Mixpanel project.
2
Review & select flags
Browse all retrieved flags, filter by status or type, assign the target Mixpanel SDK per flag, and export a shareable migration report before importing.
3
Import to Mixpanel
One click creates all selected flags in your Mixpanel project via the Management API. Use dry-run mode to preview without writing. Generated code samples show the new SDK call sites.
